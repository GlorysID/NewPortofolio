# Menambah proyek quest

1. Salin `_template.mdx` jadi file baru di folder ini (mis. `05-nama-proyek.mdx`).
2. Isi frontmatter wajib: `title`, `year`, `tags`, `link`, `summary`.
3. Tulis detail proyek sebagai MDX di bawah frontmatter.
4. Push → build ulang otomatis → kertas baru muncul di papan (maks 12).
